# デザイン思考スキル

廣田章光『デザイン思考 マインドセット＋スキルセット』の考え方を参考に、人の体験から問題を見つけ、案を比較し、小さく試す方法まで具体化するAIエージェント用スキルです。著者・出版社の公式または公認プロジェクトではありません。

## 主な機能

- 観察した事実と推測を分けて問題を整理
- POV・HMWによる問題設定、複数案の比較
- 異なる専門視点のエージェントによる独立発案・相互批評・改訂・再評価
- 試作品、検証項目、続行・変更・中止の条件を作成
- 事業モデル、価格、収支仮説、チーム学習の検討

複数エージェントの委任機能が使える環境では実際に委任します。使えない環境では、一つのエージェントによる視点別検討であることを明記します。AIによる検討は実際の顧客調査や実地検証の代わりにはなりません。

## 導入

このリポジトリを、利用するエージェントのスキルディレクトリ内の `design-thinking` フォルダに配置します。既存の同名スキルがある場合は内容を確認してから統合してください。

```text
skills/
└── design-thinking/
    ├── SKILL.md
    ├── agents/openai.yaml
    └── references/
```

## 使い方

```text
$design-thinking を使い、大学図書館の席を探しにくい問題について考えて。
複数の専門視点から発案し、相互批評と改善を行い、試す方法まで具体化してください。
```

予算、対象者、期限、変えられない条件がある場合は一緒に指定します。

## 公開版の範囲

手順、参照メモ、作業テンプレートを収録しています。書籍本文・スキャン・OCR・個人用の検索スクリプト・PC内のパスは含みません。原文の確認には利用者が適法に入手した書籍を参照してください。

複数エージェントの進め方、根拠ID、検証の判定条件、収支計算などは、このスキルによる実務上の補足です。書籍固有の方式や著者の直接引用として扱わないでください。
