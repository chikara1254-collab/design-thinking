# 書籍と参照範囲

廣田章光『デザイン思考 マインドセット＋スキルセット』。書籍の考え方を基礎に、操作できる手順へ言い換えたスキル。著者本人の公認スキルではない。モデルを再学習したという意味でもない。

## 混同しないこと

- ダブルダイヤモンド：問題発見・問題解決それぞれの拡散／収束。本書の段階名は発見・定義・開発・統合（pp.49-50）。
- オーウェン：縦が現実／具体と象徴表現／抽象、横が分析と統合。四領域は事実、仮説・推測、洞察・コンセプト、プロトタイプ（pp.50-54）。四段階を一度通れば完了という図ではない。
- 第6章POVは **状況・人・問題・理由・解決後の体験** の五要素（pp.136-138）。一般的な3要素の書式だけに置き換えて本書の全要素と称さない。
- ナゲットは、まだ意味を説明できなくても気になる観察情報（pp.122-123）。インサイトは単に観察した言葉ではなく、問題・望む体験と実現手段を結び、見通しが開ける洞察（pp.52、136）。対談の表現は対談者の実務上の説明として扱う。
- 第8章は実在の一人を使ったペルソナやプロトペルソナを認める（pp.174-179）。第12章の伊藤氏は、N=1を見つけ、同様の悩みを持つ集団の存在を確認し、その集団を表すペルソナへ進むと説明する（pp.303-310）。同じ説明に潰さず、探索と商品化の段階に合わせる。
- 初期の一人の強い必要性は発見の価値がある。市場の広がりや採算が証明されたわけではない（pp.160-163、175-176、250-252、305-310）。
- 試作の3Rは Rough / Rapid / Right。Rightは検証したい側面を正しく表現することで、初めから正解・完成品を作る意味ではない（pp.199-200）。
- 6つの帽子は全員で同じ視点へ切り替える。一人ずつ固定の役を振る方式ではない（pp.229-231）。
- 書籍の事例、説明用の架空例、ユーザーの事実を混同しない。
