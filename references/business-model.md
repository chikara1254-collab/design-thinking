# ビジネスモデルへの適用

本書の人間中心、ジョブ、問題発見、試作、企業の実践を事業検討へつなぐ。以下の事業整理表・収支式・実験の判断基準は**実務への補足**であり、本書独自の様式ではない。第6～8章・第10章・第12章が主な土台。

## 1. 売り物より先に、役立つ体験を定める

「誰が、どの場面で、何を達成したいか」「今はどうしているか」「既存手段の何が困るか」を確認する。ユーザーの既定のアイデアは尊重し、そのアイデアが役立つ条件と限界を探す。

利用者、受益者、購入決定者、支払者が同じか分けて考える。例えば学校向けサービスでは、生徒が使っても学校が決め、別部門が予算を持つ場合がある。この構造も現場確認前は仮説。

N1の深い理解は発見の入口になる。一人に見つけた困りごとの存在と、その困りごとを持つ人数・支払意思は別の証拠である。「誰にも売れない」と早期に切り捨てず、似た状況の人に共通するか調べる。第12章 pp.308–310では、実在のN1から同様のグループを確かめ、対象を抽象化する説明がある。第8章のプロトペルソナなどと同一視しない。

## 2. 事業のつながりを一枚にする

| 要素 | 明らかにすること |
|---|---|
| 対象・状況・ジョブ | どんな人の、いつ起きる、何を前進させたいという要求か |
| 価値 | 導入後にどんな体験・行動・結果が変わるか |
| 代替手段 | 競合、手作業、我慢、何もしない選択と比べるとどうか |
| 届け方 | 認知、試用、購入、利用、困った時、継続・退出までの体験 |
| 支払と収入 | 誰が、何に、いつ、いくら払うか。支払の根拠はあるか |
| 提供体制 | 人、技術、仕入先、協力者、設備、運用・品質管理 |
| 費用・負荷 | 初期費用、固定費、利用ごとの費用、対応時間、資金繰り |
| 継続できる理由 | 顧客が戻る理由、提供側の能力、無理のない運営条件 |
| 未確認の条件 | 成立を左右する仮説を重要度と不確実性で並べる |

空欄を架空の事実で埋めない。既知／仮説／未確認を各項目に付ける。売上だけで顧客の体験や運営上の問題を覆い隠さない。

## 3. 仕組みの違う選択肢を比較する

単品販売、従量制、定額、仲介、企業向け契約などは選択肢。必ず定額やアプリにするわけではない。まず既存の人・場所・手順を組み替えて価値を出せないかも検討する。

比較は、望まれる体験、実現性、事業性、不確実性に分ける。見栄えの良い平均点だけで選ばず、「ここが成立しなければ事業にならない」という条件を示す。珍しいが可能性のある案には、少額で確かめる余地を残す。

## 4. 数字を扱うとき

同じ期間・単位にそろえて、売価 P、1件あたり変動費 V、販売件数 Q、期間固定費 F とすると、簡略化した期間利益は `(P − V) × Q − F`。損益分岐件数は `F ÷ (P − V)` で、1件の限界利益が正の場合に限る。整数の件数なら切り上げる。

手数料、返品、配送、決済、顧客対応、値引き、広告、作業時間をどこに含めたか明示する。広告費を固定費にも変動費にも二重計上しない。無料の自分の労働にも継続可能な上限がある。仲介では流通総額と手数料収入を混ぜない。税や会計上の利益の正確な判断には追加の確認が必要。

仮の数字で計算した場合は冒頭に「試算」と書き、低・中・高の条件や成立に必要な最低件数を示す。予測が当たるような精密さを装わない。黒字の見込みと、仕入・入金の時差に耐える現金があることも別問題。

価格、規制、市場規模、競合、現在の企業状況を使うときは現在の一次資料を確認し、出典と時点を付ける。本の刊行時の事例を現在の実績として扱わない。

## 5. 最も危うい仮説を小さく試す

| 未確認のこと | まず試せるもの | 結果から言える範囲 |
|---|---|---|
| 困りごとがあるか | 最近の具体的な経験の聞き取り、現場の観察 | 存在と状況。人口全体の頻度は別調査 |
| 提案の意味が伝わるか | 説明カード、紙の画面、体験の寸劇 | 理解。需要・購入・継続の証明ではない |
| 運用できるか | 手動の小規模提供、業務の通し稽古 | 実施条件、時間、失敗箇所。規模拡大は未確認 |
| お金を払うか | 条件と価格を明示した選択・予約・購入の検証 | 発言、予約、実支払を区別。送信・公開・課金は別途タスクの許可範囲に従う |
| 続けて使うか | 期間を区切った利用の追跡 | 観測期間内の再利用と離脱。長期継続は未確定 |

「いいね」「欲しい」「使いやすい」を売上の証明にしない。評価が高いのに利用されないなら、問題の優先度、利用場面、切替負担、価格など別の説明を比較する。

試験には費用・時間の上限、見る行動、判断条件を先に置く。少人数の探索で有意差や市場全体の成功確率を断定しない。根拠が足りないときは事業案を決定済みにせず、次に確かめる最小の一歩を具体化する。

非営利・学習・生活の問題では、実務上の補足として「予算・時間・協力者の面で続けられるか」を考える。収益化を無理に目的へ加えない。
